# SupplierHub — база поставщиков, прайсов, заявок и КП

## Работает онлайн

**https://supplierhub-026o.onrender.com**

Открывается с телефона и компьютера, ничего устанавливать не нужно.
На iPhone: Safari → «Поделиться» → «На экран Домой» — будет иконка.

## Что умеет

- **Поиск** товара по базе (рус/англ/узб, опечатки, синонимы): цены по возрастанию,
  самый дешёвый выделен, рядом поставщик, контакт и кнопка звонка.
- **Заявка**: загрузи фото / PDF / Excel — приложение найдёт позиции, покажет
  закупочную цену, спросит наценку и сделает **КП** в Excel с реквизитами компании.
- **Поставщики**: база с контактами (телефон, e-mail, WeChat).
- **Прайс**: загрузка прайсов (Excel, PDF, фото, CSV).
- **Изменения**: что подорожало и что подешевело.
- **КП**: история коммерческих предложений со скачиванием.
- **Реквизиты**: данные компании для КП.

## Технически

Python (стандартная библиотека) + SQLite, один файл `server.py`.
На сервере: Docker, Tesseract OCR (рус+eng), pypdf, openpyxl, Pillow.
Запуск: `python server.py` (порт из переменной `PORT`).

## Ограничения бесплатного плана

- Засыпает после 15 минут без запросов — первый заход ~50 секунд.
- База при перезапуске восстанавливается из репозитория; загруженные на хостинге
  прайсы могут сброситься. Для постоянного хранения нужен платный диск.

## Локальный запуск / Windows-версия

Архив `SupplierHub_Windows.zip`, внутри `Установить.bat`.
